# D440A seeded replay table (nextgsim#462). Written by the replay, not by hand.
#
# Provenance
#   Scenario: config/demo-ai-paging/d440a-scenario.yaml (6 gNBs, one TAC, 120 m
#   apart; horizon 20000 ms; connected 15 s, paged 10..30 s after release).
#   Model-free rows: cargo test -p nextgsim-gnb --features demo-d440a-ai-paging \
#     --lib d440a::replay -- --nocapture
#   onnx rows: the same test with --include-ignored and ORT_DYLIB_PATH, run by
#   the CI model-verify job on the pinned ONNX Runtime 1.23.2 (d440b reference
#   model, a one-step constant-velocity graph: about 1 s ahead, not ML).
#   Every row is asserted exactly (the replay is deterministic), and every
#   line is checked against itself: its rate and Wilson interval must be what
#   its own hits and calls give, its mean possible for its hit count, and each
#   McNemar p-value what its counts give.
#
# Reading it
#   AMF model: amfd paging.strategy recommended-first. Attempt 1 goes to the
#   recommended gNBs; every retransmission goes to all six. PAGINGs counts every
#   PAGING message of an MT call, and a missed first attempt costs six more.
#   hits = first-attempt hits; interval = Wilson 95% for the hit rate.
#   Routes: constant-turn routes are ct's own motion model (ct is in-model);
#   straight routes are lsq's; turn-change routes are neither's. The 50-seed
#   block is one draw. Read the 2000-seed rows for comparisons, and compare
#   modes within a family: a family whose route leaves coverage redraws on its
#   own (477 straight, 803 turn-change of 2000 seeds are not paired with their
#   constant-turn run), so families are not like-for-like with each other.
#   McNemar: an exact two-sided test on the seeds only one of ct and lsq hit
#   on attempt 1 (same seeds, same family).
#   Non-normative: positions are simulator ground truth (TS 38.300 §16.20.2).
#
