Why NextGSim?

The first simulator with built-in 6G AI-native intelligence.

🤖

Autonomous AI Agents

Intent-based networking with RL-powered agents. Express goals ("optimize slice latency") and the agent figures out handovers, load balancing, and resource allocation autonomously.

📡

Semantic Communication

Neural encoder/decoder codecs that transmit meaning, not bits. ONNX-based learned compression with joint source-channel coding (JSCC) that adapts to SNR in real-time. 2-10x bandwidth reduction.

🛰

Federated Learning

Privacy-preserving distributed ML: FedAvg, FedProx, secure aggregation with x25519. Gaussian/Renyi differential privacy, Byzantine-robust aggregation (Krum, trimmed mean).

🗺

ISAC Sensing

Integrated Sensing and Communication — joint radar-comm waveforms, multi-sensor fusion (EKF + Bayesian), ML positioning (DNN, LSTM, Transformer), SLAM-like environment mapping.

🧠

Knowledge Graphs

NKEF with semantic search, RAG-ready context generation, temporal entity tracking, distributed replication, and formal ontology validation. Powers all AI agent decision-making.

⚙

Pure Rust Stack

Zero C dependencies from SCTP to ASN.1 PER. Single static binary. NAS 5G, NGAP, RRC, GTP-U, SCTP — all implemented natively. Compile anywhere Rust runs.

NWDAF — 4-Layer Analytics (TS 23.288)

Layer 4: Autonomous Actions
Adjust handover params · Cell power · Load balancing
Layer 3: Prescriptive
UE mobility · NF load · Abnormal behavior · QoS · Service experience
Layer 2: Predictive (ONNX)
Trajectory prediction · Load forecasting · Time-to-overload
Layer 1: Real-Time
Z-score anomaly detection · RSRP/SINR monitoring · Cell load

Handover types: signal-based, mobility-predicted, load-balancing, and coverage-optimized. Integrates with NKEF for knowledge enrichment and Agent for autonomous execution.

Agent — Intent-Based Autonomous Networking (TR 23.700-80)

Intent System

Declarative intents: Handover, ModifySlice, CreateSlice, OptimizeResources, TriggerLoadBalancing. Each intent specifies constraints, priority, and deadline. Conflict detection across competing intents with priority-based resolution.

RL Learning

Q-learning with experience replay. State: network load, active UEs, latency, success rate. Reward: intent success, cost, safety metrics. Agents improve from every execution outcome.

Multi-Agent Coordination

Hierarchical roles (Network > Region > Cell). Agent types: Mobility, Resource, QoS, Security, Slicing. Composite intents for cooperative goals. Safety guardrails with forbidden rules.

Extended NAS & RRC Procedures

NAS Procedures

Emergency registration — unauthenticated attach for emergency services. Configuration update — network-initiated UE parameter refresh (GUTI, TAI list, allowed NSSAI). Service request — UE-triggered transition from CM-IDLE to CM-CONNECTED for uplink data or paging response.

RRC Procedures

RRC Re-establishment — RLF (Radio Link Failure) detection triggers re-establishment to the best neighbour cell; AS security re-keyed from stored NH/NCC. RRC Resume — UE transitions from RRC_INACTIVE to RRC_CONNECTED, resuming suspended context without full re-registration.

ISAC — Integrated Sensing & Communication (TR 22.837)

Sensing Methods

ToA, TDoA, AoA, ZoA (elevation), RSS, Doppler, RTT measurements. OFDM-radar waveform design with configurable sensing/comm split and range/Doppler resolution.

ML Positioning

4 model types: DeepPositioning (DNN), TrajectoryLstm, TransformerTracking, FingerprintCnn. Feature extraction across time and space dimensions. Multi-target tracking.

Environment Mapping

SLAM-like occupancy grid mapping. Multi-sensor fusion with Extended Kalman Filter + Bayesian estimation. Sensing-as-a-Service API for application subscriptions.

Semantic Communication — Task-Aware Transmission

Raw Data (Image/Video/Audio)
↓ Neural Encoder (ONNX) ↓
Semantic Features (task-relevant only)
↓ JSCC (SNR-adaptive: high → more symbols, low → fewer) ↓
Channel Symbols
↓ Neural Decoder ↓
Reconstructed Task Output

Rate-distortion optimization (Lagrangian). Quality metrics: cosine similarity, MSE, PSNR, top-k accuracy. Importance weighting allocates bits to task-critical features. Goal-oriented coding transmits only what matters. Codec trained via federated learning (FL integration).

Federated Learning — Privacy-Preserving Distributed ML (TR 23.700-80)

Aggregation Strategies

FedAvg (weighted averaging), FedProx (regularized for heterogeneity), SecAgg (encrypted with x25519 key exchange). Asynchronous FL with staleness weighting.

Privacy Mechanisms

Gaussian differential privacy with gradient clipping. Renyi DP composition tracking. Zero-concentrated DP (zCDP) accounting. UE gradients never leave the device unencrypted.

Byzantine Robustness

Krum (multi-distance scoring), trimmed mean, coordinate-wise median. Detects and filters malicious participant updates. Gradient compression: top-k, 1-bit, ternary quantization (32x bandwidth reduction).

Hierarchical Aggregation

3-tier: UE trains locally (via SHE edge) → gNB aggregates nearby → Regional aggregates multiple gNBs → Cloud final aggregation. Model versioning and distribution.

SHE & NKEF — Compute Placement & Knowledge Intelligence

SHE: 3-Tier Compute (TS 23.558)

LocalEdge (<10ms), RegionalEdge (<20ms), CoreCloud (unlimited). Workload placement by latency/compute constraints. Auto-scaling, SLA monitoring, TEE attestation. Scheduling: ClosestToEdge, OptimalLatency, LoadBalanced.

NKEF: Knowledge Graph

Entity types: gNB, UE, Cell, AMF, UPF, Slice, PDUSession, Service, Analytics, Agent, Intent. Directed relationships with properties. TF-IDF + ONNX vector embeddings for semantic search.

NKEF: RAG Integration

Context builder with relevance scoring, token limits, relationship awareness. Powers all agent decision-making. Temporal tracking (entity history), distributed replication, formal ontology validation.

AI Infrastructure — ONNX Inference Engine

The nextgsim-ai crate provides the ML backbone for all 6G functions.

ONNX Runtime

Load any ONNX model. Batch inference, multi-input tensors, graph optimization (O0-O3). Float32/Float16/Int64 tensor types.

GPU Acceleration

Execution providers: CPU, CUDA (NVIDIA), CoreML (Apple), DirectML (Windows), TensorRT (optimized). Model warmup for consistent latency.

Specialized Pipelines

IsacPipeline (sensing ML), SemanticPipeline (codec), FlTrainer (federated), XrTrafficModel (metaverse). Per-inference latency/throughput metrics.

UE Feature Flags

UE 6G modules (SHE, ISAC, Agent, FL, Semantic) are gated behind cfg(feature) Cargo flags. Omit the feature to get a lean 5G-only UE binary with no 6G overhead — useful for large-scale UE load tests.

Docker Compose

A docker-compose.yaml is provided for full RAN simulator deployment. Brings up nr-gnb and nr-ue containers with pre-configured networking, ready to connect to a NextGCore AMF/UPF stack.

Config Feature Flags

gNB config supports runtime 6G feature flags: she_enabled, nwdaf_enabled, nkef_enabled, isac_enabled, agent_enabled, fl_enabled, energy_enabled. Each flag controls whether the corresponding task is spawned at startup.

ONNX Centralisation

nextgsim-ai is the sole workspace crate that depends on ort (ONNX Runtime). All other crates that need inference depend on nextgsim-ai — eliminating duplicate linking and binary size bloat.

Key Workflows

End-to-end procedures from UE attach to AI-driven optimization.

UE Registration via gNB (TS 23.502 §4.2.2)

UE→RRC Setup Request (RLS link-layer over UDP)→gNB
gNB→RRC Setup (SRB1 established, cell config)→UE
UE→RRC Setup Complete + NAS Registration Request (SUCI, requested NSSAI)→gNB
gNB→NGAP Initial UE Message (NAS PDU, TAI, user location)→AMF (SCTP)
AMF→Nausf_UEAuthentication (SUCI → SUPI via SIDF)→AUSF → UDM
AMF→NAS Authentication Request (5G-AKA RAND, AUTN)→UE
UE→NAS Authentication Response (RES*) — verify AUTN, compute HRES*→AMF
AMF→NAS Security Mode Command (EA1/EA2, IA1/IA2, ABBA)→UE
UE→NAS Security Mode Complete (NAS ciphered from here)→AMF
AMF→NGAP InitialContextSetup (K_gNB, security capabilities, allowed NSSAI)→gNB
gNB→RRC Security Mode + RRC Reconfiguration (SRB2, DRB setup)→UE
AMF→NAS Registration Accept (5G-GUTI, allowed NSSAI, TAI list)→UE
UE→NAS Registration Complete — UE state: RM-REGISTERED, CM-CONNECTED→AMF

Full RLS→RRC→NGAP→NAS stack simulated end-to-end. UE stores GUTI for subsequent registrations. gNB maintains UE context with AS security keys derived from K_gNB.

PDU Session Establishment (TS 23.502 §4.3.2)

UE→NAS PDU Session Establishment Request (SST:1, SD:0x010203, DNN:internet)→gNB
gNB→NGAP UL NAS Transport (PDU Session ID, S-NSSAI, request transfer)→AMF
AMF→Nsmf_PDUSession_CreateSMContext (SUPI, DNN, S-NSSAI)→SMF
SMF→PCF policy fetch: QoS rules, session AMBR, PCC rules→PCF
SMF→PFCP Session Establishment (PDR + FAR + QER + URR rules)→UPF
UPF→PFCP Response (F-TEID for GTP-U N3 tunnel)→SMF
SMF→IP: 10.45.x.x allocated (bitmap pool), QoS flow with 5QI=9→AMF → gNB
gNB→RRC Reconfiguration (add DRB for PDU Session, QoS flow mapping)→UE
UE→User data: IP packets → GTP-U encap → N3 tunnel → UPF → N6 → DN→Internet

GTP-U tunnel established between gNB and UPF. UE TUN interface created with assigned IP. PFCP rules define packet detection (PDR), forwarding (FAR), QoS enforcement (QER), and usage reporting (URR).

Xn Handover (TS 23.502 §4.9.1)

UE→RRC Measurement Report (RSRP/RSRQ for neighbor cells)→Source gNB
Src gNB→A3 event triggered: neighbor RSRP > serving + hysteresis→HO Decision
Src gNB→Xn Handover Request (UE context, PDU sessions, target cell)→Target gNB
Tgt gNB→Admission control → Handover Request Ack (DL forwarding GTP TEIDs)→Src gNB
Src gNB→RRC Reconfiguration (target cell config, new C-RNTI)→UE
UE→Sync to target cell → RRC Reconfiguration Complete→Target gNB
Tgt gNB→NGAP Path Switch Request (new N3 GTP tunnel info)→AMF → SMF
SMF→PFCP Session Modification (update PDR/FAR to target gNB TEID)→UPF

Seamless mobility with data forwarding during handover. Source gNB forwards buffered DL data to target via GTP tunnel. UE re-derives AS security keys from NH/NCC chain.

6G Task Lifecycle — Runtime Spawn (gNB & UE)

Config→gnb.yaml flags: she_enabled, nwdaf_enabled, nkef_enabled, isac_enabled, agent_enabled, fl_enabled, energy_enabled→gNB init
gNB init→Spawn 7 6G tasks at runtime: SheTask, NwdafTask, NkefTask, IsacTask, AgentTask, FlAggregatorTask, EnergyTask→Task runtime
Config→ue.yaml flags: she_enabled, isac_enabled, agent_enabled, fl_enabled, semantic_enabled (Cargo feature gates)→UE init
UE init→Spawn 5 6G tasks when features enabled: SheMobileTask, IsacUeTask, AgentUeTask, FlClientTask, SemanticTask→Task runtime
AgentTask→Wired to AgentCoordinator: register() → submit_intent() → process()→AgentCoordinator
FlAggregatorTask→Wired to FederatedAggregator: collect client updates → aggregate → distribute global model→FederatedAggregator
IsacTask→Sensing data processed via IsacManager → position estimates forwarded to NWDAF→IsacManager

6G tasks are spawned at runtime based on config flags — not compiled away. UE 6G modules are additionally gated behind Cargo cfg(feature) for lean builds without 6G overhead. Docker-compose is available for full RAN simulator deployment.

ISAC Sensing + ML Positioning (6G)

gNB→Configure OFDM-radar waveform (sensing subcarriers, PRS-like RS)→RF Front-end
gNB→Transmit joint comm+sensing signal (shared spectrum, no guard band)→Air Interface
gNB Rx→Collect echo: ToA, AoA, RSS, Doppler from reflected signals→ISAC Engine
IsacTask→Route sensing data through IsacManager for pipeline coordination→IsacManager
ISAC→Feature extraction: range-Doppler map, angle spectrum, temporal features→ML Pipeline
ML→DeepPositioning CNN inference → (x, y, z) estimate with confidence→Fusion
ML→TransformerTracking → velocity + trajectory prediction→Fusion
Fusion→EKF + Bayesian sensor fusion → refined position (sub-meter accuracy)→NWDAF
NWDAF→Analytics event: UE_LOCATION update → handover recommendation to RRC task→RRC / Agent

Joint communication and sensing on shared 6G waveform. IsacTask channels all sensing data through IsacManager. ISAC engine runs radar processing in parallel with data demodulation. NWDAF position analytics feed directly to the RRC task for predictive handover decisions. ML models trained via federated learning across gNBs.

Semantic Communication Pipeline (6G)

UE App→Raw data input (image 1920x1080, video frame, audio segment)→Semantic Tx
Encoder→ONNX neural codec: extract task-relevant semantic features only→Latent Space
JSCC→Joint source-channel coding: SNR-adaptive symbol mapping→Modulator
Channel→Bandwidth: 2-10x reduction vs Shannon (task-oriented compression)→gNB Rx
JSCC Rx→Adaptive demodulation (matched to channel state feedback)→Decoder
Decoder→ONNX neural decoder: reconstruct task output (not raw data)→gNB App
gNB App→Semantic similarity metric: SSIM/BLEU → feedback to encoder rate control→UE

Beyond-Shannon paradigm: transmit meaning, not bits. JSCC eliminates the separation between source and channel coding. Compression ratio adapts in real-time to channel conditions and task importance. ONNX runtime enables cross-platform model deployment.

Federated Learning Round (6G)

FlAggregatorTask→Wired to FederatedAggregator — drives round lifecycle: collect, aggregate, distribute→FederatedAggregator
FL Server→Broadcast global model v(n) + training config (epochs, LR, batch)→Selected UEs
UEs→Local SGD training on private data (never leaves device)→Local Models
UEs→Differential privacy: add calibrated Gaussian noise (epsilon=1.0)→DP Gradients
UEs→Gradient compression: top-k sparsification or 1-bit quantization→Compressed
UEs→Upload compressed updates (over-the-air or dedicated channel)→gNB Edge
gNB Edge→Hierarchical aggregate: Byzantine-robust filter (Krum/Median)→Regional
Regional→FedAvg (weighted by samples) or FedProx (proximal term mu=0.01)→FL Server
FL Server→SecAgg verify → global model v(n+1) → convergence check→NWDAF
NWDAF→Model registry update → redistribute to participating UEs/gNBs→Network

Privacy-preserving distributed ML across the RAN. Three-tier aggregation (UE → gNB → Regional → Cloud) minimizes backhaul. Byzantine filtering protects against poisoning attacks. SecAgg ensures server never sees individual updates.

Autonomous Agent Decision Loop (6G)

NWDAF→Analytics event: cell-123 PRB utilization 85%, QoS degradation predicted — handover recommendation sent to RRC task→RRC / Agent
NKEF→Knowledge graph query: 3 UEs eligible for HO, neighbor cells at 40% load→Agent
AgentTask→register() with AgentCoordinator → submit_intent(TriggerLoadBalancing) → process()→AgentCoordinator
Agent→State encoding: [PRB=0.85, QoS_violation=2, neighbors=[0.40, 0.55, 0.30]]→RL Policy
RL Policy→Q-learning action selection: TriggerLoadBalancing (Q=0.87, epsilon=0.1)→Intent
Agent→Conflict resolution: check safety constraints, no conflicting intents→Validator
Agent→Execute: Handover UE-1, UE-2 to cell-456 (lowest load neighbor)→gNB
gNB→Xn Handover executed → cell-123 PRB drops to 60%→Result
Result→Reward: +0.8 (PRB↓, QoS✓) → Q-table update → experience replay buffer→Agent

Closed-loop autonomous network optimization. AgentTask registers with AgentCoordinator, submits intents, and drives the process loop. NWDAF analytics now feed handover recommendations directly to the RRC task. Agent observes state, reasons with NKEF knowledge graph, acts via RL policy, and learns from outcomes.

SHE Compute Offloading (6G)

UE App→Task request: ML inference (model=ResNet50, deadline=10ms, data=2MB)→SHE Manager
SHE→Score tiers: UE(latency=50ms), Edge(12ms, 2ms net), Cloud(5ms, 15ms net)→Placement
SHE→Decision: Edge placement (meets deadline, minimizes energy)→gNB Edge
gNB Edge→Execute inference → result (class=vehicle, confidence=0.94)→UE App
SHE→Log: actual_latency=8ms, energy=0.3J → update placement model→NWDAF

Smart Heterogeneous Environment manager evaluates compute tiers (UE/Edge/Cloud) for each task based on latency budget, energy cost, and network conditions. Placement decisions improve over time via feedback loop.

Quick Start

Get a UE and gNB simulator running in minutes.

Build from Source

# Clone the repository git clone https://github.com/NextgCoreLab/nextgsim.git cd nextgsim # Build all 20 crates cargo build --release # Binaries: nr-gnb, nr-ue, nr-cli ls target/release/nr-*

Run gNB + UE

# Terminal 1: Start gNB (connects to AMF) ./target/release/nr-gnb --config config/gnb.yaml # Terminal 2: Start UE ./target/release/nr-ue --config config/ue.yaml # Terminal 3: Interactive CLI ./target/release/nr-cli

Multi-UE Simulation

# Simulate 10 UEs with auto-incrementing IMSI ./target/release/nr-ue --config config/ue.yaml --num-ues 10 # With debug logging RUST_LOG=debug ./target/release/nr-gnb --config config/gnb.yaml

Docker Compose (Full RAN)

# Start gNB + UE via Docker Compose docker compose up # With 6G features enabled (edit docker-compose.yaml config paths) docker compose up --build

Enable 6G Features (UE lean build)

# Build UE with specific 6G feature flags cargo build --release --package nextgsim-ue --features "isac,agent,fl" # Minimal 5G-only UE (no 6G overhead) cargo build --release --package nextgsim-ue --no-default-features
