CLI Reference

The six binaries a release build produces. Logging is set with RUST_LOG, not a flag. The full reference is the nr-cli Reference chapter.

nr-gnb — gNodeB Simulator

nr-gnb [OPTIONS] --config <FILE>

Start a 5G gNB that connects to one or more AMFs over NGAP and serves UEs over RLS.

-c, --config <FILE> gNB configuration YAML file (required)
-l, --disable-cmd Do not open the nr-cli command interface
# Basic usage nr-gnb --config config/gnb.yaml # With debug logging RUST_LOG=debug nr-gnb --config config/gnb.yaml

nr-ue — UE Simulator

nr-ue [OPTIONS] --config <FILE>

Start one or more 5G UEs that find a gNB over RLS, register and establish the configured PDU sessions. Needs CAP_NET_ADMIN for its TUN interfaces.

-c, --config <FILE> UE configuration YAML file (required)
-i, --imsi <IMSI> Use this IMSI instead of the config's (15 digits, optional imsi- prefix)
-n, --num-of-UE <NUM> Number of UEs, 1..512 (default 1), IMSI incremented per UE
-t, --tempo <TEMPO> Delay in ms between UE starts (default 0)
-l, --disable-cmd Do not open the nr-cli command interface
-r, --no-routing-config Do not configure TUN routing (currently only logged)
# Single UE nr-ue --config config/ue.yaml # Ten UEs, 100 ms apart (auto-incrementing IMSI) nr-ue --config config/ue.yaml -n 10 -t 100

nr-cli — Control Interface

nr-cli [OPTIONS] [NODE]

Inspect and drive running gNB and UE nodes on the same host. Nodes register in /tmp/nextgsim.proc-table/; nr-cli talks to them over UDP on 127.0.0.1.

NODE gnb, or ue0, ue1, ... for UEs
-d, --dump List the running nodes and exit
-e, --exec <COMMAND> Run one command and exit
# List nodes, then query one nr-cli --dump nr-cli ue0 -e status # UE commands info | status | ps-list | timers | deregister [normal|switch-off] ps-establish [-t <type>] [-a <apn>] [-s <sst>] | ps-release <psi> | ps-release-all | emergency-register # gNB commands info | status | amf-list | ue-list | ue-info <id> | ue-release <id> ue-suspend <id> [t380-minutes] | xn-path-switch <id> <source-amf-ue-ngap-id>

nr-loadtest — Load Test

nr-loadtest [OPTIONS]

Register many UEs against a 5G core and report the success rate; exits non-zero below 90%.

--ues <UES> Number of UEs (default 10)
--rate <RATE> Registrations per second, 0 = burst (default 5)
--gnb-addr / --amf-addr gNB and AMF addresses (defaults 127.0.0.100 / 127.0.0.5)
--base-imsi <IMSI> First IMSI (default 999700000000001)
--skip-pdu / --ping Skip the PDU session / ping after it
nr-loadtest --ues 100 --rate 20 --amf-addr 10.0.0.5 --ping

lte-enb / lte-ue — LTE eNB and UE

lte-enb --config <FILE> | lte-ue --config <FILE>

The LTE eNB (S1 Setup, S1AP, S1-U GTP-U; build with --features kernel-sctp on Linux) and the LTE UE (cell selection, RRC, EPS NAS attach, DRBs, TUN). Both read NEXTGSIM_* environment overrides.

-c, --config <FILE> Configuration YAML file (required)
lte-enb --config config/enb.yaml lte-ue --config config/lte-ue.yaml

Configuration Reference

YAML for the gNB and UE, cut down from the shipped config/gnb.yaml and config/ue.yaml. Keys are byte arrays and nci is an integer. Every key is in the Configuration Reference.

gNB Configuration (gnb.yaml)

nci: 0x000000010 # NR Cell Identity (36-bit), an integer gnb_id_length: 32 plmn: { mcc: 999, mnc: 70, long_mnc: false } tac: 1 nssai: - { sst: 1, sd: null } amf_configs: - address: 172.23.0.5 # IP or hostname port: 38412 sctp_backend: userspace # kernel for a real AMF (--features kernel-sctp) link_ip: 172.23.0.100 ngap_ip: 172.23.0.100 gtp_ip: 172.23.0.100 ignore_stream_ids: false upf_addr: 172.23.0.7 # 6G research tasks (need a --features 6g build) isac_enabled: false nwdaf_enabled: false

UE Configuration (ue.yaml)

supi: { supi_type: Imsi, value: "999700000000001" } protection_scheme: 0 home_network_public_key_id: 0 home_network_public_key: [] hplmn: { mcc: 999, mnc: 70, long_mnc: false } key: [0x46, 0x5B, 0x5C, 0xE8, 0xB1, 0x99, 0xB4, 0x9F, 0xAA, 0x5F, 0x0A, 0x2E, 0xE2, 0x38, 0xA6, 0xBC] op: [0xE8, 0xED, 0x28, 0x9D, 0xEB, 0xA9, 0x52, 0xE4, 0x28, 0x3B, 0x54, 0xE8, 0x8E, 0x6D, 0x83, 0x4D] op_type: Opc amf: [0x80, 0x00] supported_algs: { nia1: true, nia2: true, nia3: true, nea1: true, nea2: true, nea3: true } gnb_search_list: ["172.23.0.100"] sessions: - { type: Ipv4, s_nssai: { sst: 1, sd: null }, apn: internet, is_emergency: false } configured_nssai: slices: [{ sst: 1, sd: null }]
