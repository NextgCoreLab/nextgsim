CLI Reference

Command-line interface for the gNB, UE, and interactive CLI binaries.

nr-gnb — gNodeB Simulator

nr-gnb [OPTIONS]

Start a 5G gNB (gNodeB) simulator instance that connects to the core network AMF via NGAP/SCTP.

-c, --config <FILE> Path to gNB configuration YAML file (required)
-v, --verbose Enable verbose logging (TRACE level)
--log-level <LEVEL> Set log level: error, warn, info, debug, trace (default: info)
# Basic usage nr-gnb --config config/gnb.yaml # With debug logging nr-gnb --config config/gnb.yaml --log-level debug

nr-ue — UE Simulator

nr-ue [OPTIONS]

Start a 5G UE (User Equipment) simulator that connects to a gNB and performs NAS procedures.

-c, --config <FILE> Path to UE configuration YAML file (required)
-n, --num-ues <COUNT> Number of UE instances to simulate (default: 1)
-v, --verbose Enable verbose logging (TRACE level)
--log-level <LEVEL> Set log level: error, warn, info, debug, trace (default: info)
# Single UE nr-ue --config config/ue.yaml # Multiple UEs (auto-incrementing IMSI) nr-ue --config config/ue.yaml --num-ues 10

nr-cli — Interactive Console

nr-cli [OPTIONS]

Interactive CLI for runtime control of running gNB and UE instances.

-h, --host <ADDR> Control socket address (default: 127.0.0.1)
-p, --port <PORT> Control socket port (default: 9000)
# Connect to running instance nr-cli # Available commands status # Show gNB/UE status ue list # List connected UEs ue info <id> # Show UE details ue deregister <id> # Trigger deregistration
